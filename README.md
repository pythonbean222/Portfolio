# Personal Portfolio Website

## Overview

This repository contains the source code for my personal website. The purpose of this website is to serve as a central place to share information about my work, projects, experience, and professional interests.

The site is built using standard web technologies:

- HTML
- CSS
- JavaScript

It is designed as a lightweight static website that can be easily hosted and accessed online.

## Purpose

The goal of this website is to provide a simple and accessible way to showcase:

- Information about my work
- Skills and experience
- Professional background

This website acts as an online portfolio and reference point for anyone interested in learning more about my work.

## Technologies Used

- **HTML** — Structure and content
- **CSS** — Styling and layout
- **JavaScript** — Interactive elements and functionality

## Deployment

The website is deployed using **GitHub Pages**, allowing it to be hosted directly from this repository.
